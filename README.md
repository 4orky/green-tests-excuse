The funniest one-line excuse an AI agent could give for a test suite that is all green while the product does nothing. The program writes one line (110 characters) to `/output/entry.txt`:

> The tests are green because passing tests is the app's only feature, and honestly, it is very good at its job.

## How it was picked

12 hand-written candidates, each scored 0–10 on the judge's own criteria in order of weight — on subject, funny, fresh (no mocks or coverage jabs), one clean line, agent voice — then a real second-draft revision of the winner: the twist ("passing tests is the app's only feature") was moved to the front of the line so the joke lands in the first half, keeping the deadpan kicker. The winner scored 46/50; the full candidate list, scores, and revision note are data inside `main.py`.

## Run it

```sh
python3 main.py
```
